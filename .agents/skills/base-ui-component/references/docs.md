# Docs

The docs page proves the component works: every demo renders in the browser and doubles as a visual regression fixture.

## Files

- Page: `docs/data/material/components/<kebab-name>/<kebab-name>.md`.
- Demos: one folder per demo under `demos/`, in the three-file format described in `AGENTS.md` (Docs demos).
- Route: `docs/pages/material-ui/react-<kebab-name>.js`, copied from an existing page such as `react-menubar.js` with the markdown import changed.
- Navigation: an entry in `docs/data/material/pages.ts` with `unstable: true`.
- API pages: generated by `pnpm docs:api` (`docs/pages/material-ui/api/*`, `docs/translations/api-docs/*`, and the entries in `docs/data/material/pagesApi.js`). Commit the generated files.

`components` lists every public part, which links the page to each API page.

## Page outline

1. Title, description, and `{{"component": "@mui/internal-core-docs/ComponentLinkHeader"}}`.
2. An unstable warning:

   ```md
   :::warning
   Preview Card is an unstable component.
   Import it from the `Unstable_PreviewCard` subpaths.
   Its API can change in a minor release.
   :::
   ```

3. A basic demo, then one section per feature from the Base UI docs that the component exposes.
4. **Anatomy**: the parts and how they nest.
5. **Customization**: `render` (including reading Base UI state in a render function), `slots` and `slotProps`, theme `styleOverrides` and `variants`, utility classes, and the data attributes table (part, attribute, meaning) taken from the exported data attribute objects.

## Demos

- Import parts from their subpaths: `import PreviewCardTrigger from '@mui/material/Unstable_PreviewCardTrigger';`.
- Triggers always use `render`: `<PreviewCardTrigger render={<Button>Open</Button>} />`.
- Keep demos short: inline the parts, use minimal `sx`, and use `component="p"` on `Typography` headings inside demos so the page keeps valid heading levels.

Done when each demo renders in `pnpm docs:dev` without console errors, and its interaction (open, select, type) works by hand or in a browser check.
